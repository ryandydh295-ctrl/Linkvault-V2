# 🎮 LinkVault 360

A browser-based, Xbox 360-styled dashboard demo with chat, friends, DMs, a store, a soundboard, AI shell, and full theme customization.

> ⚠️ **This is a frontend-only demo.** All data (accounts, chats, DMs, friends, apps, sounds, pfps, wallpapers) is stored in your browser's `localStorage`. It is **not** multi-user, **not** secure, and **not** a real chat platform. See [Limitations](#-limitations) below.
